**Status legend.**
- `PRESENT` — the behaviour is reachable and implemented; the Desktop as-built cell contains the implementing `file:line`.
- `PARTIAL` — some user-visible sub-behaviours are implemented, others are not.
- `MISSING` — no user-facing implementation exists (a headless model alone does not count).
- `DIFFERENT` — implemented, but with a materially different user-visible semantic; the difference is stated in the row.
- `?` — the censuses do not establish the fact; the cell is marked `?` and is carried into Gaps.
- `REGISTER` — the owner is this register document itself (CON-002 maintenance; CON-006 deviation recording through the Waiver column).
- Every Waiver cell is `none`: no human-approved deviation is recorded in the round-1 evidence, so CON-006 is not satisfied for any non-parity row.
