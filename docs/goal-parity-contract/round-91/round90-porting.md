### Why these are the right tests, not neighbours

- `PlotFileWriteRefusal`: row 1 asserts the declared type and its classification; rows 2–3 drive the
  runner's own `run_args` and assert the full envelope for the missing-directory and empty-name
  caller paths. The same-named `lovelace-lang` tests are the library half; rows 2–3 map to the
  `lovelace-run` wire tests.
- `Dsp`: Sum/Product assert exactly the two samples in DspTests.cs:54/62; Sequence asserts the
  length-mismatch refusal and the matching-sequence control.
- `DenseArrayComplex`: construction asserts DType/ElementType/Numel/IsContiguous (plus shape/rank/
  precision); GetElement and AsSpan assert the same 1+2i / 3−4i pair as the C# rows.
- `IntegerToString`: 10-char `-42` writes 3 chars and `-42`; 3-char `-12345` is the false/0-written
  branch (`None`, destination untouched).
- `Parser`: chained assignment asserts `Assign(x, Assign(y, 5))` plus evaluation binding both names;
  unary plus asserts `Plus(Number("5"))` plus evaluation.
- `DomainFailureVocabulary`: each test asserts `EvaluationException` (kind and reference message) on the
  same `NumOps` operation as the C# row, plus the language envelope where one exists.
- `RelationsAndFamilies`: Integrate asserts SolvedConditional/log(x)/x > 0, SolvedExact, Unevaluated;
  Kleene asserts True/False/Unknown and the typed Unknown refusal; LogicalCanonicalization asserts every
  C# assertion at the constructor surface (`lovelace-symbolics`) with the engine companion in
  `lovelace-lang`; Piecewise asserts the C# numeric and MathIR-lowered values.
- `IntegerPow`: each row asserts its own refusal (negative exponent, zero base, zero exponent), with the
  base-first order and the three positive controls.
- `ExactnessFlag`: the corpus test mirrors the C# corpus and both directions of the leaf rule; the radical
  test mirrors the exact/inexact boundary and x^1.5 == x^(3/2); the solver test mirrors the five-equation
  `value.IsExact == (exactness != Approximate)` rule and the Exact/Approximate publication check.
