# Round 43 — the 800-atom test's wall-clock tripwire

Status: the flaky fixed-duration bound in
`lovelace-lang::assumptions_round35::eight_hundred_atoms_stay_ordered_and_fast` is replaced by a
30 s hang tripwire. The ordering assertions are unchanged. No production source, fixture, corpus
example or parity mapping was edited; `parity/rust-tests.json` was regenerated by
`parity/gen-rust-tests.ps1`, which the manifest gate requires after any Rust source edit.

## The failure

The test asserted that constructing and ordering 800 assumption atoms completes inside 2,000 ms
(debug) / 250 ms (release). Alone it passed; inside `cargo test --workspace` it did not:

| run | observed |
|---|---|
| alone, `cargo test -p lovelace-lang assumptions_round35::eight_hundred -- --nocapture` | `800 atoms: 814.0907ms` — ok |
| full workspace, parallel (the failure that blocked the manifest gate) | the same loop measured 2.37 s against the 2,000 ms bound — suiteExit=101 |

Same 800 insertions, same resulting order, different wall time: the bound was measuring how many
other test binaries were competing for the CPUs, not the code.

## The change (one test file)

`rust/lovelace-lang/src/assumptions_round35.rs`:

- The deterministic half is untouched: 800 atoms present, `order_key` non-decreasing across the
  stored sequence, first rendered atom `x > 799`, last `x > 0`.
- The 2,000 ms / 250 ms bound is gone. It is replaced by
  `const HANG_TRIPWIRE: Duration = Duration::from_secs(30);` and
  `assert!(elapsed < HANG_TRIPWIRE)`.
- The comment above the constant records what the new bound guards (non-termination / pathological
  blowup, for example an accidental quadratic per-insert path), why the old bound was wrong (it
  measured scheduling, not the code), and why 30 s is safe under parallel load: about 12x the worst
  loaded measurement (2.37 s) and 23x the unloaded one (about 1.3 s), so only a hang or an
  algorithmically different implementation can reach it.

The test name is unchanged, so the manifest's claimed test path still resolves.
