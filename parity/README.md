# The parity contract

This directory is the measurement system for the C# -> Rust migration. It exists because the
migration's completion must be *demonstrated*, not asserted: every claim below is a command with an
exit code, and every gate fails closed.

The authoritative contract is [docs/parity/contract-v2.md](../docs/parity/contract-v2.md). It
defines 262 requirement IDs in 25 families plus seven ID-less obligations. If a requirement
disappears from the contract, gate-requirements.ps1 reports contract drift; if one is missing from
the ledger, it reports a missing row. Nothing can be quietly dropped.

## The artifacts

| Artifact | Generated by | What it is |
|---|---|---|
| oracle.json | hand-written, one SHA | The frozen C# oracle: commit, project, runner path, source directories. |
| build-oracle.ps1 | -- | Verifies the pinned sources are byte-identical to the SHA, then builds and executes the C# runner. Refuses a dirty tree. |
| census.json | tools/census (reflection) | Every C# test case: 15 projects, 2 105 methods, 6 209 cases (theory rows enumerated, not just methods). Deterministic: two runs produce the same SHA-256. |
| manifest.toml | gen-manifest.mjs from the census | One disposition per census case: ported / consolidated / excluded / deferred, with a reason and a target phase. |
| rust-tests.json | gen-rust-tests.ps1 | Every Rust test that exists, per crate, plus the measured suite exit code. |
| projects.toml | hand-curated | One disposition per C# production project (19), with a Rust path or an explicit absence. |
| requirements.json | gen-requirements.mjs from the contract | Every requirement ID with status, owner, phase and evidence, plus the ID-less obligations. |
| cli-matrix.json | hand-curated | One row per RUN-001..RUN-014 flag, with argv, stdin, semantic asserts and comparison mode. |
| diff/ | -- | The differential runner: deterministic generator, structural comparator, minimiser, regression corpus. |
| scorecard.json | run-all.ps1 | The only summary a release decision may read. |

## The gates

| Gate | Command | Proves |
|---|---|---|
| Oracle | powershell -File parity/build-oracle.ps1 -Verify | The C# reference is the pinned commit, its sources unchanged, and its runner answers protocol v1. |
| Census | gate-census.ps1 | The census is complete over the 15 test projects, internally consistent, and reconciled with the 2 087 reference figure. |
| Manifest | gate-manifest.ps1 | Every census case has exactly one disposition; every claimed Rust test exists and its suite ran green. |
| Projects | gate-projects.ps1 | All 19 C# production projects are dispositioned; absent ones carry a reason and a phase. |
| Requirements | gate-requirements.ps1 | All 262 IDs and 7 obligations are present with an owner, a phase and evidence for any met/partial claim. |
| Fixtures | gate-fixtures.ps1 | The C# oracle and the Rust runner each reproduce all 20 golden envelopes under the reference's own normalisation (revision, elapsed, elapsedTime, timings). |
| CLI | gate-cli.ps1 | RUN-001..014 behave like the oracle with identical argv/stdin; a row the oracle cannot satisfy is itself a failure. |
| Differential | node parity/diff/run.mjs --cases 5000 --seed 1 | Both runners agree on 5 000 generated cases across arithmetic, precision, arrays, symbolic, records, errors, syntax and registry. |
| Mutation | mutate.ps1 | Twelve deliberate faults are each caught by the gate that is supposed to catch them, and the reverted tree passes again. |
| Scorecard | run-all.ps1 -Cases 5000 | Every dimension above, from live commands, in one fail-closed report. |

## Regeneration order

    powershell -File parity/build-oracle.ps1          # verify + build the oracle
    parity/tools/census/bin/Release/net10.0/census.exe --out parity/census.json
    node parity/gen-manifest.mjs                       # census -> manifest
    powershell -File parity/gen-rust-tests.ps1         # Rust test inventory + suite run
    node parity/gen-requirements.mjs                   # contract -> requirements ledger
    powershell -File parity/run-all.ps1 -Cases 5000

The census tool has no package references and reads the built test assemblies by reflection, because
the VSTest testhost cannot run in this environment (OpenProcess is denied to it). That limitation is
recorded as a capability gap, not hidden: the C# test suite is unverifiable here, while the C#
runner is executable and is the behavioural oracle.

## Reading the numbers honestly

- A disposition is not coverage. manifest.toml can be 100 % dispositioned while 0 % of cases map to
  a Rust test; the scorecard and gate-manifest.ps1 print both numbers.
- A skipped dimension is never a pass. run-all.ps1 records SKIPPED explicitly and exits non-zero if
  anything failed.
- A gate that cannot run is a failure (exit 2), not an empty pass.
